# Advertio Cargo — Cinematic Remotion Launch

20-second, 9:16 Instagram Reels (1080×1920) Persian promotional motion-graphics video for Advertio Cargo. The platform **connects senders to travelers**; Advertio does not operate flights or carry parcels itself.

## Project isolation
All source lives in `videos/advertio-cargo-tech-launch/`. Dedicated workflow `.github/workflows/render-advertio-cargo-remotion.yml` runs **only this folder**, not other existing video projects. Development branch: `feature/advertio-cargo-remotion-launch`; main remains untouched until a separate merge.

## Five scenes
| 0–3s | Explosive parcel hook: «بسته داری؟ مسافرش رو پیدا کن!» |
| 3–7s | Portrait diagonal layout: a sender in Canada and a traveler to Iran |
| 7–12s | Advertio Cargo mock listing in a large smartphone, with glass HUD and clear DEMO label |
| 12–16s | Toronto-to-Tehran curved flight route with a detailed nose-forward commercial aircraft |
| 16–20s | ADVERTIO CARGO, genuine logo source, Persian CTA and Advertio.net |

Design: luminous white tech-corporate aesthetic, navy, azure and cyan. Three-dimensional/isometric vector illustrations, layered depth, deterministic springs, rotating HUD rings and particles. The background music is a **new original procedural synthesizer track** generated by `scripts/make-audio.py`, not an excerpt from existing music.

## Brand assets
Only the authentic user-uploaded **Advertio Logo.png** was used as the source for the logo. `public/brand/Advertio-Logo-Original-Source.png` is a pixel-preserving-shape, smaller optimized rendition of that uploaded source for use at small sizes; it is **not AI generated**. The original larger user upload remains the approved master. No approximated or recreated logo is allowed. The Persian font files under `public/fonts/` reuse the repository's original Vazirmatn Regular and Bold font blobs, without downloading replacement fonts.

The screen in the phone is **a fictional interface mockup clearly labeled «نمونه نمایشی / DEMO LISTING»**; it does not claim the listing is real.

## Output modes
- `npm run render:quick`: ten JPG storyboard stills, generated using one reused browser (run `python3 scripts/contact-sheet.py` for montage).
- `npm run render:preview`: actual H.264 MP4, **540×960, 15 fps, 300 frames / 20 seconds**, with an original ambient instrumental bed.
- `npm run render:final`: actual H.264 MP4, **1080×1920, 30 fps, 600 frames / 20 seconds**. Run only on explicit workflow selection.

## Local use
Node.js 22+, Python 3.12+, npm, Chromium/Chrome and ffmpeg (Remotion can download compatible versions if needed).
```bash
cd videos/advertio-cargo-tech-launch
npm install --no-audit --no-fund
npm run lint
npm run render:preview
# optional
npm run render:quick
python3 scripts/contact-sheet.py
# production only
npm run render:final
```

## Instagram Reels 9:16 update

This revision switches both compositions to **true portrait** (native 1080×1920 final; 540×960 preview). Scenes are **recomposed**, not letterboxed or cropped from 16:9. Critical headlines and the original Advertio brand mark stay inside the portrait content-safe area. Top-of-screen numerical counters (for example, `01 / 05` and `SECURE LINK`) have been removed. A new detailed top-down twin-engine passenger aircraft includes cockpit windows, 38 cabin windows, winglets, doors, engines, metallic highlights and navigation lights; its nose follows the tangent of the animated Toronto → Tehran path, correcting the travel direction. Quick stills and contact sheet are portrait as well.

### Correct preview scaling and visual validation
Preview composition uses the **same 1080×1920 authoring canvas** as Final at 15 fps, and the Remotion CLI renders it with `--scale=0.5` into 540×960 pixels. This prevents nested AbsoluteFill/Sequence viewports from truncating the bottom of portrait scenes. CI inspects an actual 9.5-second preview frame and asserts that rich content remains visible in the lower half, instead of merely checking MP4 dimensions.

### Enhanced detail revision
The video now uses the original-drawn `AirlinerDetailed` with layered swept wings, winglets, flap/aileron seam geometry, two distinct turbofan nacelles with inlet fans, paired cabin windows, cockpit glazing, doors, nose sensor, reflective fuselage and navigation lights. The aircraft's nose follows the flight-path tangent at every frame. `CargoParcelDetailed` adds shipping labels, folding, tape, barcode and 3D shading. `ProductPhone` builds a readable demo (not a real listing) with airport codes YYZ → IKA, route information, cargo card, four listing fields, chat action and bottom navigation. `TerminalBackdrop` and `AirportDistrict` add miniature airport architecture, baggage equipment and runway markings. Corner counters remain deleted.
