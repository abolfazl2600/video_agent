# Approved render-ready WEBP source assets

The project contains its original five storyboard concepts as **optimized 540×960 WEBP** files under [storyboard_frames](./storyboard_frames/) and all nine separate transparent WEBP typography plates under [typography](./typography/). Both collections are fully committed in GitHub.

These are derived from the previously generated source images and are optimized specifically for the 540×960 Quick Preview.

Use `ADVERTIO_RENDER_MODE=quick-preview npm run render` from the project directory to create `quick-preview.mp4`. Assets are NOT loaded from external URLs.

For higher-resolution publication, replace the backdrops with approved source-resolution artwork, then request a Final render. The original Advertio logo must never be recreated or AI-generated.
