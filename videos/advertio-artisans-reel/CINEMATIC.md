# Cinematic edition

The original six PNGs and final.mp4 remain untouched. New output: renders/cinematic-final.mp4 (50 seconds, 1080x1920, 30 fps, silent). Six gently drifting camera moves and five one-second feathered paper transitions with small custom line-art motifs: flight, textile diamond, coin, browser and parcel/share. The artwork and Persian text are never rewritten. No additional logo or claims.

Run from this folder with Python 3.12, FFmpeg, numpy and opencv-python-headless: python render_cinematic.py. The dedicated workflow validates all 1500 frames and publishes only the new MP4.
