# Advertio Dark Tech Flight
Source: `reference.jpg` from the project's supplied photo (first frame). Runtime scene: `scene.mjs` / Three.js SVGRenderer. Preview: `index.html` / GSAP. Final overlay and MP4: `finish.py`.
```bash
npm install
npm run build
npm run render
```
Output: `flight-dark-tech-tiktok.mp4`, 1080×1920, 30 fps, 15 seconds. Optional: `npm run samples` for representative frames; `npm run lint` for JS syntax.
The official Advertio logo must only ever be used from the original uploaded Advertio Logo.png; no AI recreation.
